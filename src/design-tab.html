Map preview and zoom

The search results map is a compact 165-pixel preview, like the Asset POC. Click the preview or its expand button to open a full-size interactive map. Result markers remain selectable in both views; the expanded map supports panning and zooming.

Framework and runtime

The app uses the same no-framework approach as the Asset POC: static HTML, CSS, and browser-native JavaScript. The Loqate API key field is in the address search section. The FastAPI proxy exposes /health, /heartbeat, /api/addresses/search, and /api/addresses/retrieve; interactive OpenAPI documentation is available at /docs. The proxy can run in a local Podman container.

Without an API key, the app only returns its two built-in sample address searches. With a key, the browser sends the X-Loqate-Api-Key header to the proxy, which forwards Find and Verify requests to Loqate. The key is persisted in localStorage and is not protected as a production secret.

Address formatting and standard

When available, Loqate's AddressFormat response determines the formatted address lines: each line identifies response fields, and non-empty values are joined for display. UPU S42 is the addressing reference used by the POC; the app does not implement a separate address standard engine.

Limitations: the proxy has no authentication, cache, account system, or secure server-side key store. Map display requires Leaflet CDN and OpenStreetMap access. This demonstration does not establish address deliverability, ownership, or legal status.
